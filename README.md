## ✨ المميزات
- 🎨 واجهة عربية بسيطة تدعم الوضع الليلي
- ⚡ تسجيل في ثوانٍ مع معالجة ذكية للأخطاء
- 🔒 لا تخزن أي بيانات شخصية – خصوصيتك أولوية
- 🆓 مفتوحة المصدر 100% – مجانية للأبد

---

## 🚀 التشغيل السريع

```bash
# 1. تحميل المشروع
git clone https://github.com/haithemgdi/adhahi.dz.git
cd adhahi.dz

# 2. تثبيت المتطلبات
pip install customtkinter requests Pillow

# 3. التشغيل
python main.py
```

## 📝 طريقة الاستخدام
1. افتح البرنامج وأدخل: **رقم التعريف الوطني** • **الهاتف** • **الولاية**
2. حل رمز التحقق (CAPTCHA) الظاهر
3. اضغط **تسجيل** وانتظر تأكيد النجاح ✅

💡 *نصيحة:* استخدم اتصالاً مستقراً وتجنب الضغط المتكرر لتجنب الحظر المؤقت.
