## 🛠️ المتطلبات | Requirements
- **Python 3.8 أو أحدث** مثبت على جهازك
- اتصال إنترنت مستقر
- لا حاجة لصلاحيات `Administrator` أو `Root`

لتثبيت المكتبات المطلوبة، نفذ الأمر التالي في الطرفية:
```bash
pip install customtkinter requests Pillow
```

## 📦 التثبيت والتشغيل | Installation & Usage
1. **تحميل المشروع**
   ```bash
   Git clone https://github.com/haithemgdi/adhahi.dz.git
   cd adhahi.dz
   ```
   *(أو قم بتحميل الملفات مضغوطة مباشرة من صفحة الإصدارات)*

2. **تشغيل البرنامج**
   ```bash
   python main.py
   ```

3. **إدخال البيانات**
   - افتح النافذة الظاهرة
   - أدخل: `رقم التعريف الوطني`، `رقم الهاتف`، `الولاية`
   - حل رمز التحقق (CAPTCHA) الظاهر في الواجهة
   - اضغط على زر **تسجيل** وانتظر تأكيد العملية

💡 **ملاحظة:** يُنصح بتشغيل البرنامج على شبكة مستقرة وتجنب الضغط المتكرر لتجنب الحظر المؤقت من الخوادم الرسمية.
