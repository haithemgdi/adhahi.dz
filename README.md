# 🐑 Adhahi DZ Registration Tool | أداة التسجيل في منصة أضحي

أداة مجانية مفتوحة المصدر لمساعدة المواطنين الجزائريين على التسجيل في منصة "أضحي" بسهولة وسرعة. تم تطوير هذه الأداة لتكون بسيطة واحترافية لتسهيل العملية على الجميع.

## ✨ المميزات (Features)
*   **واجهة عصرية:** تصميم مريح وسهل الاستخدام (Dark Mode).
*   **تجاوز المشاكل التقنية:** معالجة آلية للـ API لتفادي أخطاء المتصفح العادية.
*   **خفيفة وسريعة:** لا تستهلك موارد الجهاز وتعمل مباشرة.
*   **مجانية بالكامل:** صدقة جارية لكل "زوالي" يحتاج للتسجيل.
